## 这份笔记是怎么来的（重要）

我一开始打算按你说的「扒视频 + 语音识别」来做，实际试过一轮，结论是**这条路不如官方逐字稿**：

- B站这个视频**没有字幕轨**（字幕接口返回空），未登录还只能下载**每集前 4 分钟的试看片段**（11 集下下来字节数一模一样，就是这个原因）。
- 走语音识别的话：本机 sc-pipeline 的 torch 是 CPU 版跑不动，学习仓库的 venv 是 CUDA 版但缺 `cublas64_12.dll`，只能用 CPU 跑小模型，16 小时音频不现实，而且 AI 配音的专有名词（`pytest`、`None`、`f-string`）识别错得会不少。

所以改用了更准的路子：**哈佛官方发布的逐字稿 + 官方 Notes + 官方 SRT 字幕时间轴**。

- 正文内容 → 官方逐字稿 `https://cdn.cs50.net/python/2022/x/lectures/N/lang/en/lectureN.txt`（讲师课堂口述全文，含即兴解释、现场翻车、学生提问）
- 代码 → 官方 Notes `https://cs50.harvard.edu/python/notes/N/`（逐字稿里代码是口述的，比如 "print, open paren, quote unquote hello world"，靠 Notes 还原成可运行代码）
- 时间轴 → 官方 SRT 字幕，每 5 分钟取一个锚点

中文配音版是基于同一门课的官方视频做的，内容与英文原版逐字稿一一对应，所以笔记能精确对齐你看的视频。

**P1（课程简介，4 分 17 秒）没有官方逐字稿**，那份是本地语音识别（small 模型）转的，见文末，仅供参考。

## 每份笔记的结构

统一格式，方便定位：

1. **本讲速览** —— 一句话主题 + 15-20 条知识清单 + **时间轴表格**（时间点 → 主题，对应视频位置）
2. **正文** —— 按课堂讲解顺序分节，每节标题带 `[mm:ss]` 时间标注。包含：
   - 讲师**为什么**引入这个概念
   - 代码的**演进过程**（笨版本 → 改进版 → 最终版，全部保留）
   - **现场翻车**（漏括号、逻辑错、报错信息）与修复
   - 学生提问与回答
3. **本讲代码速查** —— 本讲出现的所有语法集中列出
4. **本讲易错点** —— 5-15 条

## 配套文件

- `../CS50P-分集速览与习题.md` —— 41 道官方习题（PSet 0–8）逐题的考点、易错点、骨架代码。学完一讲就去做对应那组题。

## 建议用法

1. 看一集视频前，先扫一遍对应笔记的「本讲速览」，知道这集会讲什么。
2. 看视频时，用笔记的**时间标注**跳到你没听懂的片段重看。
3. 看完后做对应 PSet 的题，卡住时回笔记找对应章节。
4. 复习时只看每份笔记末尾的「代码速查 + 易错点」。

## 附：P1 课程简介（本地语音识别，仅供参考）

这一段没有官方逐字稿，是用本机 faster-whisper small 模型（CPU）转写的，专有名词识别有误（"拍散"= Python、"辩量"= 变量、"政责表达式"= 正则表达式、"CTG"= 问题集）。下面是我修正后整理的内容：

**David Malan 的课程导言（4 分 17 秒）**

- CS50 主课覆盖计算机科学的各个领域与编程艺术，而**这门课专注 Python 语言本身**。
- 课程路线（与本笔记的讲次一一对应）：
  1. **函数与变量** —— 先学核心概念解决小问题，再组合小模块解决大问题
  2. **条件语句** —— 用代码表达逻辑：条件成立就执行，不成立就不执行
  3. **循环** —— 让代码一遍又一遍重复执行
  4. **异常** —— 写代码一定会出问题（可能是你的问题，也可能是别人的），写**防御性代码**主动捕获并妥善处理异常，让用户看不到报错
  5. **库** —— 复用别人或自己之前写的第三方代码，不重复造轮子
  6. **单元测试** —— 写代码来测试自己的代码。业界的好习惯：测试通过说明代码正确；更重要的是**以后改动代码时重跑测试，确认没有破坏原有功能**
  7. **文件 I/O** —— I/O 即输入/输出。不只把信息放内存，还要**持久化**到磁盘的文件和文件夹里
  8. **正则表达式** —— 在 Python 里定义模式，用来**验证数据**（确保用户输入是你想要的）和**提取数据**
  9. **面向对象编程** —— 一种编程范式，可以在代码里表示现实世界的事物
  10. **其它** —— 还会接触过程式编程（写很多函数从上到下解决问题）、函数式编程；最后给更多工具与基础，让你课程结束后能独立前行
- 每周形式是：**讲座介绍概念 → 通过问题集（Problem Set，即编程项目）加深理解**，把知识用到实际问题上。
- 课程结束时你会解决大量**现实生活中的典型案例**——无论你想在技术领域编程，还是在艺术、人文、社科、自然科学领域应用，都会掌握必要的编程术语与解决实际问题的能力。
- **这门课不需要任何编程基础**，可以零基础开始；也可以在 CS50 之前或之后选修（如果你想更熟练掌握 Python）。
