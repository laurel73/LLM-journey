## 练习 (1)

**题目**：假设我们有一些数据 x₁, x₂, …, xₙ ∈ ℝ。我们的目标是找到一个常数 b，使得最小化 Σᵢ (xᵢ − b)²。

a. 找到最优值 b 的解析解。
b. 这个问题及其解与正态分布有什么关系？

### a. 最优值 b 的解析解

损失函数

L(b) = Σᵢ (xᵢ − b)²

对 b 求导。把平方展开成 (xᵢ − b)(xᵢ − b)，对 b 求导得每一项贡献 −2(xᵢ − b)，所以

dL/db = −2 Σᵢ (xᵢ − b) = −2 ( Σᵢ xᵢ − n b )

令导数为 0：

Σᵢ xᵢ − n b = 0  ⟹  **b = (1/n) Σᵢ xᵢ**

即最优值就是这批数据的**平均值**。

二阶导 d²L/db² = 2n > 0，所以这个驻点是极小值点。

### b. 与正态分布的关系

假设各 xᵢ 独立同分布，且服从正态分布 N(b, σ²)。正态密度为

p(x) = 1 / (√(2π) · σ) · exp( −(x − b)² / (2σ²) )

独立 ⇒ 似然是各样本概率的**连乘**；取负对数后连乘变连加：

−log P = (n/2) · log(2πσ²) + (1 / (2σ²)) · Σᵢ (xᵢ − b)²

第一项与 b 无关，是常数。所以「最小化负对数似然」与「最小化 Σᵢ (xᵢ − b)²」是同一件事：

**在正态噪声假设下，最小二乘解就是 b 的极大似然估计。**

（顺带：σ² 的极大似然估计是 (1/n) Σᵢ (xᵢ − b)²。）

## 练习 (2)

**题目**：推导出使用平方误差的线性回归优化问题的解析解。为了简化问题，我们可以忽略偏置 b（通过向 X 添加所有值为 1 的一列来做到这一点）。

a. 用矩阵和向量表示法写出优化问题（将所有数据视为单个矩阵，将所有目标值视为单个向量）。
b. 计算损失关于 w 的梯度。
c. 通过将梯度设为 0 并求解矩阵方程来找到解析解。
d. 什么时候解析解方法可能比使用随机梯度下降更好？这种方法何时会失效？

### a. 优化问题

设 X 为 n × (d+1) 的矩阵（那一列全为 1 的列已吸收偏置），y 为 n 维目标向量，w 为 d+1 维参数向量。优化问题为

**min_w L(w) = ½ ‖Xw − y‖² = ½ (Xw − y)ᵀ (Xw − y)**

### b. 损失关于 w 的梯度

**∂L/∂w = Xᵀ(Xw − y) = XᵀXw − Xᵀy**

说明两点：

- 梯度必须与 w 同形状（d+1 维），上面这个式子满足。
- 若损失写成 ‖Xw − y‖²（不带 ½），梯度就是 2Xᵀ(Xw − y)。两种写法都对，取决于前面是否保留 ½；本解答按带 ½ 的版本。

### c. 解析解

令梯度为 0：

XᵀXw − Xᵀy = 0  ⟹  **XᵀXw = Xᵀy**

两边左乘 (XᵀX)⁻¹，得

**w* = (XᵀX)⁻¹ Xᵀy**

### d. 何时比 SGD 更好、何时失效

**更好的场合**：n（样本数）和 d（特征数）都不大时。解析解的总运算量约为 n·d² + d³，且 XᵀX 这个 d×d 的矩阵要整个放进内存；两边都小时它便宜，而且一次算完、结果是精确的、不需要调学习率。另外，同一个 X 要反复解不同的 y 时解析解很划算 —— 分解只跟 X 有关，做一次就能复用。

**失效的情形有两种**：

一是 **XᵀX 不可逆**（行列式为 0），方程解不出来。典型来源：

- X 的两列成比例（例如第 2 列 = 第 1 列 × 2）。这等于同一份信息写了两次，方程退化成同一个方程，消元时会出现除以 0，程序抛 `LinAlgError: Singular matrix`。数学上表现为解不唯一。
- 样本数少于未知数个数（n < d）。此时 X 的秩最多为 n，而 XᵀX 是 (d+1)×(d+1) 的，秩也最多为 n，必然不可逆。这种情况下程序常常**不报错**，但给出的解由噪声主导（条件数极大，输入微小的扰动会让解剧烈变化），结果没有意义。

二是 **XᵀX 可逆但规模太大**，用不起。n 或 d 很大时，n·d² + d³ 的运算量算不动，d×d 的内存也放不下（例如 d = 10⁵ 时 XᵀX 需要约 80 GB）。这不是"解不出来"，是"算不起"。

## 练习 (3)

**题目**：假定控制附加噪声 ε 的噪声模型呈指数分布，也就是 p(ε) = ½ exp(−|ε|)。

a. 写出模型 −log P(y|X) 下数据的负对数似然。
b. 请尝试写出解析解。
c. 提出一种随机梯度下降算法来解决这个问题，哪里可能出错？（提示：当我们不断更新参数时，在驻点附近会发生什么情况？）请尝试解决这个问题。

### a. 负对数似然

由 p(ε) = ½ exp(−|ε|)，单个样本的概率为

p(yᵢ | xᵢ) = ½ exp( −| yᵢ − xᵢᵀw | )

样本独立 ⇒ 似然是连乘：

P(y | X) = Πᵢ ½ exp( −| yᵢ − xᵢᵀw | ) = (½)ⁿ · exp( −Σᵢ | yᵢ − xᵢᵀw | )

取负对数（连乘变连加）：

**−log P(y | X) = n · log 2 + Σᵢ | yᵢ − xᵢᵀw |**

第一项与 w 无关，所以最小化它就是最小化 Σᵢ | yᵢ − xᵢᵀw |，即**绝对误差之和（L1 损失）**。

对照练习 (1)(2)：高斯噪声 → 平方误差；指数分布（拉普拉斯）噪声 → 绝对误差。

### b. 试写解析解

绝对误差下**没有**练习 (2) 那样的闭式解。令梯度为 0 得到的是"正残差与负残差个数相平衡"的条件，而不是一个可以直接解出的线性方程组。

只有**常数模型**（只有一个参数 b）有干净答案：L(b) = Σᵢ | yᵢ − b | 的最小点就是样本的**中位数**。

而且偶数个样本时，使 L(b) 最小的 b 是**一整段区间**，解不唯一 —— 所以题目写的是"请尝试写出"。

### c. SGD 算法、它会出什么问题、怎么解决

记第 i 个样本的残差 rᵢ = xᵢᵀw − yᵢ（预测减真实），单个样本的损失 ℓᵢ = | rᵢ |（与 | yᵢ − xᵢᵀw | 相同）。

**提出算法。** | r | 对 r 的导数分两段：r > 0 时为 +1，r < 0 时为 −1（r = 0 处不存在）。又 ∂rᵢ/∂w = xᵢ，由链式法则

∂ℓᵢ/∂w = ± xᵢ

每步取一个样本，沿负梯度方向更新：

**w ← w − η · ∂ℓᵢ/∂w**

即：预测偏高（rᵢ > 0）时 w ← w − η xᵢ；预测偏低（rᵢ < 0）时 w ← w + η xᵢ。

**哪里会出错。** 平方误差的梯度是 rᵢ xᵢ，里面带着残差本身，残差越小步子越小；绝对误差的梯度里只有符号，大小恒为 ‖xᵢ‖，**与残差多大无关**。

于是在最优点附近：各样本的推动方向相反、互相抵消，但每个样本给出的推力都是满格的；参数被交替推向两侧，η 为常数时**摆动幅度不衰减，迭代不收敛** —— 参数一直在最优解附近来回震荡。（η 越小摆动范围越小，但不会自己停。）

附带一个小问题：| r | 在 r = 0 处不可导，程序里通常取 sign(0) = 0，残差恰好为 0 的那个样本这一步不动。

**怎么解决。**

① **学习率随时间衰减**：让 η → 0。每步位移与 η 成正比，摆动幅度随之趋于 0，迭代收敛。代价是后期收敛变慢。

② **磨圆（光滑近似）**：用 √( r² + δ² ) 代替 | r |，其导数为 r / √( r² + δ² )。当 | r | ≫ δ 时该导数 ≈ ±1，与原问题几乎一致；当 | r | ≪ δ 时该导数 ≈ r / δ，即"残差越小、步子越小"这个性质恢复了。代价是最小点被移动了 O(δ) 量级，δ 越大越平滑但偏得越多。

③ **改用专门算法**：常数模型直接取中位数；一般线性情形属于分位数回归，可化为线性规划求解。
