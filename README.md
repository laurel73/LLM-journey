## 作业归档流程（手机 → 电脑）

1. 手机上写完作业，打包成 `cs50p_weekN.zip` 之类的压缩包，传到电脑桌面。
2. 说一句「整理桌面作业」，我负责：解压 → 按周归档到对应目录 → 更新进度 → `git add` / `commit` / `push`。
3. 原始压缩包保留在桌面不动，作为备份。

压缩包命名约定：`cs50p_weekN.zip`（N 是周次）。换课之后照此推广，比如 `d2l_week2.zip`。
